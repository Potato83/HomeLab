## Эксплуатация

От root на Alpine:

```sh
rc-service chatbot status
rc-service chatbot restart
rc-service chatbot stop
rc-service chatbot start
```

Секреты: `/srv/bots/chatbot/.env`. После их изменения нужен restart. Журналы: `/var/log/chatbot/`; logrotate — daily/maxsize 10M, три архивных файла, copytruncate. Исходные env перед настройкой прокси сохранены root-only в `/root/bots-env-before-start-20261105/`.

Откат первого развёртывания: остановить службу и исключить её из default (`rc-update del chatbot default`), сохранив код, секреты и данные. Удалять базы для отката не требуется. После будущих миграций нужен совместимый backup базы.
