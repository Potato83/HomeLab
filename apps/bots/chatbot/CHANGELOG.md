# Изменения

## 05.11.2026 — исправление игровых кнопок

- Исправлен разбор ID с двоеточиями в PvP, отказе от вызова, КНБ и блэкджеке. Поддержаны уже сохранённые ID без миграции базы.
- Ошибки отсутствующей, истёкшей и завершённой игры, а также некорректной кнопки теперь различаются. В журнал пишется только тип причины отказа.
- Добавлены тесты полного пути callback → обработчик → SQLite: ставки, отказ, оба хода КНБ, версии кнопок BJ, чужие участники, повторные нажатия без повторной выплаты.
- На старом коде воспроизведены два сбоя; на исправленном прошли 57 тестов в контейнере без сети и секретов. База и финансовая логика не изменены.

## 05.11.2026 — администраторы и подсказки команд

- `ADMIN_IDS` принимает несколько Telegram ID через запятую; старый `MY_ID` остаётся резервной настройкой.
- Добавлены `/admin` и `/add` в персональное меню команд администраторов.

## 05.11.2026 — подготовка к публикации

- Приведены к общему виду README, SECURITY, ignore-правила и описание проверок.
- Подробная прежняя инструкция сохранена в docs/guide.md.
- Ограничение запуска тестов и незавершённое развёртывание записаны в docs/release-status.md.
- Добавлено скрытие секретов в логах и traceback; подготовлены регрессионные тесты. Деплой GitHub ограничен ручным запуском в environment production; контейнеру задан pids_limit.
- Обновлены закреплённые зависимости после проверки предупреждений PyPI; требуется прогон тестов совместимости.

## 05.11.2026 — проверка перед серверным запуском

- Пройдено 42 тестов в изолированных контейнерах; обновлены устаревшие фикстуры и ожидания без ослабления проверок доступа.
- Подготовлен нативный OpenRC с supervise-daemon. Запуск остановлен до восстановления SSH; службы ещё не установлены.
