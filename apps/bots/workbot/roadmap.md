# Бот для поиска стажировок и junior-вакансий

## Цель первой версии

Находить подходящие стажировки и junior-вакансии, присылать их в Telegram и работать на личном сервере. Бот помогает находить объявления; решение об отклике принимает пользователь.

## Текущие критерии

- Направления мониторинга с 0.14: ИБ, DevSecOps, DevOps/SRE/Platform и MLOps/ML Platform/Data Engineering; выбираются через Telegram.
- Уровень: стажировка или junior, включая формулировки «стажёр», intern, trainee, «начинающий специалист», «без опыта» и сходные. Образовательные программы без стажировки не считаются вакансиями. Мероприятия с 0.14 отслеживаются отдельно от вакансий.
- Локация: офис или гибрид в Санкт-Петербурге; удалённая работа — любой регион.
- При первом запуске прислать подходящие объявления, которые уже найдены; затем присылать новые.
- Канал уведомлений: Telegram.
- Fast Track: присылать подходящие направления с пометкой «набор не подтверждён», если форму проверить не удалось; при подтверждении — одно дополнительное сообщение.
- Сервер: Alpine Linux с Podman; есть виртуальная машина с Ubuntu и Docker. Основной вариант размещения — Podman на Alpine, если проверка совместимости пройдёт успешно; Ubuntu/Docker — запасной вариант.

## Как должна работать первая версия

1. Периодически опрашивать подключённые источники. Начальный ориентир — раз в час с возможностью изменить интервал для каждого сайта.
2. Для каждого источника использовать отдельный адаптер: доступный официальный API, публичную выдачу или обработку страницы после проверки доступности и условий сайта.
3. Приводить полученные данные к общему виду: название, компания, ссылка, источник, описание, уровень, город, формат работы, дата публикации и зарплата — если они доступны.
4. Применять фильтры по направлению, уровню и расположению. Для начала — настраиваемые группы слов и правил. Вакансии с неизвестным городом или форматом по умолчанию присылать с пометкой «нужно уточнить», если остальные критерии подходят.
5. Сохранять находки и состояние доставки в SQLite. Не отправлять одно и то же объявление повторно; отслеживать ошибки доставки и повторять неуспешные попытки.
6. При первом успешном опросе каждого источника отправлять подходящие уже опубликованные объявления; при последующих — новые. Привязать начальную загрузку к каждому источнику, чтобы добавление новых сайтов не пропускало существующие вакансии.
7. Присылать в Telegram название, компанию, город и формат, зарплату при наличии, ссылку и причину совпадения. Если данных нет, явно указывать это.
8. Показывать состояние источников и записывать ошибки. Пустая выдача и ошибка сайта — разные состояния.

## Источники

### Реализованные источники (версия 0.15)

- Яндекс — отдельные направления стажировок ИБ, с проверкой статуса набора.
- Kaspersky — все страницы вакансий и отдельные описания кандидатов по ИБ.
- Бастион — полный список вакансий с проверкой количества, метками опыта, города и формата.
- КРОК — выдача направления «Кибербезопасность» со сверкой полноты по общему каталогу.
- МТС — публичный API поиска по словам ИБ, полная пагинация каждого запроса и точные строковые ссылки.
- X5 — направление ИБ в стажировках, проверка текущего статуса набора.
- PT Start — программа стажировки с обучением, этап оплачиваемой стажировки, направления ИБ и явный статус набора.
- PT Fast Track — отдельные направления ИБ, собственные условия работы, явное различение подтверждённого и непроверенного набора.
- Сбер — публичный API, категории ИБ и поиск по словам во всех категориях, полная пагинация, справочники опыта и графика, собственные условия вакансий.
- Хабр Карьера — полный раздел ИБ, метаданные карточек и собственные описания, уровень, города и удалёнка.
- Яндекс — общий публичный каталог вакансий, пагинация по курсору и собственные задачи/требования выбранных направлений.
- CTFtime — API календаря, даты с часовым поясом, онлайн/география, условия участия, деление периода при достижении лимита.
- ODS — пагинация активного календаря, собственные карточки и явное различение непроверенной и подтверждённой регистрации.

Фильтр аудитории мероприятий добавлен в 0.16: можно оставить любые события, только явно подходящие начинающим, либо также включать события с неизвестным уровнем с предупреждением.

## Реализовано в тестовой версии 0.1

- CLI: `demo`, `preview`, `once`, `run`, `status`, `chat-id`.
- `demo` и `preview` не требуют токена и не меняют историю доставки.
- Команды Telegram: `/start`, `/help`, `/status`, `/check`.
- Обработка закрытия и повторного открытия набора; защита от одновременных циклов с одной базой.
- Сетевые ошибки и изменение разметки фиксируются отдельно от отсутствия совпадений.
- Образовательные программы без стажировки и мероприятия не подключены.
- Подробности запуска — в `README.md` и `docs/deployment.md`.
