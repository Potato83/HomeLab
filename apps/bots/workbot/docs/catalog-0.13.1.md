# Расширение каталога 0.13.1

Проверка: 28 октября 2026 года. Добавлено 26 веб-ссылок; итоговый каталог содержит 56 веб-ссылок и две прежние локальные заметки в 10 разделах. Исходные записи сохранены. Каталог читается через `/sites` и CLI `python -m botwork sites`; собственный BOTWORK_SITES заменяет встроенный файл целиком.

## Поиск вакансий новых направлений

Прямые запросы Хабр Карьеры: [DevOps](https://career.habr.com/vacancies?q=DevOps&type=all), [SRE](https://career.habr.com/vacancies?q=SRE&type=all), [Platform Engineer](https://career.habr.com/vacancies?q=Platform%20Engineer&type=all), [DevSecOps](https://career.habr.com/vacancies?q=DevSecOps&type=all), [MLOps](https://career.habr.com/vacancies?q=MLOps&type=all), [ML Platform](https://career.habr.com/vacancies?q=ML%20Platform&type=all), [Data Engineer](https://career.habr.com/vacancies?q=Data%20Engineer&type=all). Все страницы запросов ответили HTTP 200 с заголовком «Работа и вакансии» при сетевой проверке; это проверка доступности ссылок, а не полноты или наличия подходящих результатов.

Также добавлены [ODS Jobs](https://ods.ai/jobs) и [GitJobs](https://gitjobs.dev/), куда перенаправляет прежний адрес jobs.cncf.io. GitJobs — международная площадка Open Source; есть фильтры Internship, уровня и формата.

Запросы не задают уровень и расположение автоматически. На сайте нужно выбрать стажёр/junior и проверить удалёнку либо офис/гибрид в СПб. Для международных вакансий отдельно проверять допустимую страну найма: remote сам по себе не гарантирует возможность работать из России. Data Engineering — смежное направление, а не синоним MLOps. Разные названия одной роли могут требовать разных запросов.

## Границы изменения

Добавление в каталог не подключает источник и не включает уведомления. Настройки и правила автоматического поиска вакансий ИБ сохранены. Автоматический сбор мероприятий и отдельных направлений занесён в roadmap. Каталог не обещает открытый набор, наличие бесплатных билетов или соответствие всех результатов личным фильтрам.

Личные названия, примечания, скрытые ссылки и добавления по-прежнему применяются поверх встроенного каталога по стабильным ID. Для обычного обновления встроенного каталога импорт или изменение базы не требуется; работающий процесс подхватит файл при следующей команде, а контейнеру нужен обновлённый образ. Проверка не отправляла сообщения в Telegram.
