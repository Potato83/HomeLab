# Команды

Работают только в личном чате OWNER_ID и только от владельца.

| Команда | Результат |
| --- | --- |
| /jobs [слово] | Пять свежих вакансий из последнего снимка |
| /events [слово] | Пять ближайших событий |
| /keywords [слова через запятую] | Показать или заменить слова |
| /exclude [слова через запятую] | Показать или заменить исключения; минус очищает |
| /check | Проверка в фоне; повтор через минуту |
| /status | Состояние включённых источников |
| /help | Справка |

Слова внутри фразы ищутся вместе, разные фразы разделяются запятыми. До 32 слов/фраз длиной до 60 символов. /jobs Python и /events CTF временно выбирают другое слово для просмотра сохранённой выдачи; подписка остаётся прежней.

Во время проверки команды доступны. Изменение слов отменяет старую проверку; устаревший результат не попадёт в базу. Следующий сбор использует новые слова. При /start бот убирает прежнюю клавиатуру.

Карточка содержит название, компанию/организатора, дату или зарплату, город, условия формата, совпавшие слова и ссылку. Отсутствующие условия не угадываются; неизвестная регистрация помечается предупреждением.
