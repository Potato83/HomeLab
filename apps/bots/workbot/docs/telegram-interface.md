# Интерфейс Telegram

`/start` и `/menu` открывают главную страницу. Постоянные кнопки под полем ввода доступны только в личном чате владельца:

| Кнопка | Действие |
| --- | --- |
| 🔎 Проверить | Проверить источники сейчас |
| ⚙️ Настройки | Показать текущий профиль и быстрые настройки |
| 📌 Мои вакансии | Открыть сохранённые вакансии и отклики |
| 🌐 Каталог | Найти карьерные сайты и полезные ссылки |
| 📡 Состояние | Посмотреть очередь и ошибки источников |
| 📊 Сводка | Посмотреть обратную связь по карточкам |
| 📋 План на сегодня | Напоминания, следующие действия и старые отметки откликов |
| 📚 Помощь | Открыть справку по всем командам |
| 💼 Вакансии | Найти вакансии в сохранённой базе с фильтрами и страницами |
| ⏰ Напоминания | Посмотреть личные сроки и действия |
| 🗂 Профили | Создать, выбрать или удалить профиль кнопками |
| 📤 Экспорт откликов | Получить CSV со статусами и заметками |

## Настройки

На компактной панели видны редактируемый профиль, направления, уровни, города, формат и режим доставки. Кнопки позволяют поставить мониторинг на паузу, включить подборки, изменить мероприятия в выбранном профиле, выбрать стажировки или стажировки вместе с junior, удалёнку или все форматы, ИБ или все поддерживаемые направления.

Город продолжает ограничивать офис и гибрид. Удалённая работа допускается из любого региона. Сохранённые профили участвуют в поиске одновременно; для выбора профиля редактирования используются `/profiles` и `/profile use NAME`.

Кнопки «Города», «Зарплата», «Ключевые слова», «Исключения» и «Расписание» запрашивают значение следующим сообщением. Ввод можно отменить через `/cancel` или перейти к другой команде. Ожидание ограничено 10 минутами; после изменения настроек ожидаемый ввод отклоняется.

После изменения настроек бот присылает новую панель. Старые кнопки отклоняются, если профиль или настройки изменились. Полные фильтры, зарплата, ключевые слова, расписание и индивидуальные настройки источников доступны в `/settings all`.

## Карточки вакансий

В одиночном уведомлении под карточкой расположены «Сохранить» и «Не подходит». В подборке название указывается один раз на кнопке сохранения, а соседняя кнопка скрытия содержит ID карточки. Статус отклика можно изменить командой из нижней строки карточки, например `/track a1b2c3d4 applied`.

Для скрытых карточек: `/track ignored`. Для восстановления: `/track ID saved` или `/track ID remove`.

## Проверка изменений

Сценарии проверки прав на кнопки, повторных обновлений, устаревших панелей и переходов из меню выполнены в изолированном проходе версии 0.31. Сеть запрещена через seccomp, исходники и инструменты доступны только для чтения, запись — в ограниченный scratch. Отображение на телефоне и доставка через настоящий Telegram требуют отдельной проверки владельцем.
