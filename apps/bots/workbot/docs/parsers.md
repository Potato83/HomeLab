# Парсеры

Сравнение выполнено 10 ноября 2026 года по исходникам проектов.

| Проект | Подход | Решение |
| --- | --- | --- |
| [Scrapy](https://github.com/scrapy/scrapy) | Планирование запросов и повторов | Лёгкий клиент с двумя повторами 408/429/500/502/503/504 и Retry-After |
| [extruct](https://github.com/scrapinghub/extruct) | Встроенные метаданные, JSON-LD | JobPosting перед CSS в карточках Kaspersky, «Бастиона» и КРОК |
| [Scrapling](https://github.com/D4Vinci/Scrapling) | Адаптивные селекторы и браузерные загрузчики | Пока не добавлять браузерные зависимости для личного монитора |
| [hhru/api](https://github.com/hhru/api) | Документированный API | Отдельный адаптер; включается при наличии HH_API_TOKEN |

Сравнивались подходы; код этих проектов не импортировался. Новых зависимостей нет. JSON-LD читается существующими BeautifulSoup и json, без загрузки внешних контекстов и исполнения JavaScript. Поддержаны @graph и ItemList. Неоднозначные, неполные данные и чужая явная ссылка возвращают управление HTML-парсеру.

API и встроенный JSON используются для МТС, Сбера, Яндекса, Хабр Карьеры, CTFtime и ODS. Остальные адаптеры проверяют собственную разметку. Программы стажировок и специальные каталоги имеют ограниченный охват и не представляют весь рынок.

Ограничены время, запросы, размер ответа и число страниц. Retry-After свыше минуты откладывает источник до следующего цикла; 401/403/404 не повторяются. Капча и изменение структуры становятся ошибкой источника, а не пустой выдачей. Частичная выдача не заменяет полный снимок.

Адаптеры покрыты локальными фикстурами. Свежие публичные страницы Kaspersky и «Бастиона» 10 ноября распознаны как 13 и 29 карточек. Это проверяет первый каталог, а не все страницы и внешние источники.

Время проверки делится между источниками: медленный сайт не расходует время оставшихся. Подробные карточки запрашиваются для совпадений в каталоге/предпросмотре API, без отсечения senior. Слова из ещё не загруженного описания недоступны для отбора: охват зависит от каталога или полнотекстового поиска API.
