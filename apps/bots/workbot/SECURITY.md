# Безопасность

Секреты хранятся в локальном `.env` с правами `0600`; в Git включается только `.env.example`. Не прикладывайте токены, базы и журналы к issues. Если токен попал в публикацию, отзовите его у BotFather; удаления файла недостаточно.

Запускайте одну копию бота с отдельным токеном и отдельным хранилищем. Процесс работает без root, без привилегированного контейнера и без сокета управления контейнерами. Входящие публичные порты для long polling не нужны. TLS-проверку оставляйте включённой.

Перед обновлением остановите процесс и сохраните SQLite-базу вместе с WAL/SHM либо используйте SQLite backup API. Сохраняйте предыдущую версию кода/образа. Перед откатом проверьте совместимость схемы базы; простая замена образа не отменяет миграции.

Проверка исходников и тесты не гарантируют отсутствия уязвимостей. Известные ограничения текущей подготовки записаны в `docs/release-status.md`. Уязвимость сообщайте владельцу приватно через GitHub Security Advisories, если они включены; секреты не публикуйте.
