# Мониторинг Alpine

Root-owned сборщик `deploy/host/probe.py` каждую минуту публикует `/var/lib/homelab-health/host.json`. ServerBot читает снимок без дополнительных привилегий. Проверяются службы, процессы и базы ботов, сеть, время, SMART, inode, swap и обновления. Два неуспешных замера подтверждают сбой.

Адрес SSH отдельной VM задаётся через `HOMELAB_KALI_SSH_HOST` в окружении root-задания. Без него эта проверка выдаёт предупреждение.

`deploy/host/updates.py` проверяет APK и ограниченно применяет обновления: allowlist, наличие старых APK и запрет защищённых зависимостей. Автоматической перезагрузки нет.

Сборщик устанавливается в `/usr/local/lib/homelab/probe.py`, root crontab запускает его каждую минуту. Доступ к каталогу снимков на запись есть только у root. Состояние сбора проверяется по времени `host.json`.

Рядом со сборщиком устанавливается `deploy/host/control.py`. Он позволяет учитывать
ручные остановки из [панели управления](control-panel.md): выключенная пользователем
VM или служба не считается поломкой. Отметки принадлежат root, проверяются по
фактическому состоянию и не переносятся через перезагрузку хоста.
