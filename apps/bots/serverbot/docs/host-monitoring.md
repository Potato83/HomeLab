# Мониторинг Alpine

Root-owned сборщик `deploy/host/probe.py` каждую минуту публикует `/var/lib/homelab-health/host.json`. ServerBot читает снимок без дополнительных привилегий. Проверяются службы, процессы и базы ботов, сеть, время, SMART, inode, swap и обновления. Два неуспешных замера подтверждают сбой.

Ошибки сайтов WorkBot видны в сводке ServerBot и по `/status` в WorkBot.
Оповещения WorkBot в ServerBot относятся к службе, процессу и доступности базы.

Адрес SSH отдельной VM задаётся через `HOMELAB_KALI_SSH_HOST` в окружении root-задания. Без него эта проверка выдаёт предупреждение.

`deploy/host/updates.py` проверяет APK и ограниченно применяет обновления: allowlist, наличие старых APK и запрет защищённых зависимостей. Автоматической перезагрузки нет.

Сборщик устанавливается в `/usr/local/lib/homelab/probe.py`, root crontab запускает его каждую минуту. Доступ к каталогу снимков на запись есть только у root. Состояние сбора проверяется по времени `host.json`.

Рядом со сборщиком устанавливается `deploy/host/control.py`. Он позволяет учитывать
ручные остановки из [панели управления](control-panel.md): выключенная пользователем
VM или служба не считается поломкой. Отметки принадлежат root, проверяются по
фактическому состоянию и не переносятся через перезагрузку хоста.

## Место по каталогам

Из каталога ServerBot установите сборщик рядом с `probe.py` и снимите первый
замер от root.

```sh
install -o root -g root -m 755 deploy/host/disk_usage.py /usr/local/lib/homelab/disk_usage.py
/usr/bin/python3 -B /usr/local/lib/homelab/disk_usage.py
```

Добавьте строку в существующий root crontab.

```cron
17 * * * * /usr/bin/python3 -B /usr/local/lib/homelab/disk_usage.py
```

Сборщик считает выделенные блоки на файловой системе `/`. Он пропускает
точки монтирования и учитывает символические ссылки по их собственному
размеру. Снимок сохраняется в `/var/lib/homelab-health/disk-usage.json`. В Telegram откройте
`/status` → «Подробнее» → «Диски и обновления». Полоса показывает долю от
родительского каталога. Например, доли внутри `/var/lib` рассчитаны от
`/var/lib`. Занятое место по всему разделу берётся отдельно из файловой
системы. Замер ограничен двумя минутами. При сбое сохраняется предыдущий
снимок. Через три часа без успешного замера бот покажет «Нет свежего замера».
