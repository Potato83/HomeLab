# Настройки ServerBot

`config.toml` задаёт диски, датчики температуры и батареи, HTTP/process-проверки, пороги и интервалы. Пути состояния разрешаются относительно файла конфигурации.

- `/status` — сводка, кнопка «Подробнее» — ресурсы, службы, сеть и диски.
- `/logs <имя> <строк>` — журнал из разрешённых в конфигурации.
- Ежедневный отчёт: `[digest]`, час и часовой пояс.

Уведомление отправляется при смене состояния; повторные замеры не создают дубли. Восстановление отмечается отдельно. Проверки резервных копий необязательны и включаются только соответствующей секцией.

Для HTTP с авторизацией укажите имя переменной в `auth_env`, а её значение задайте в окружении. Список допустимых журналов ограничен `logs.allowed_directories` и `logs.files`.
