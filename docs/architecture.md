# Архитектура

Alpine/OpenRC запускает непривилегированные службы ботов. Данные отделены от кода, секреты задаются вне Git. ServerBot получает ограниченный снимок здоровья от root-owned сборщика.

OmniRoute работает в Podman с ограничением ресурсов; nginx управляет доступом к API и панели. Административный доступ осуществляется через VPN и SSH.

Код приложений отделён от ОС-зависимых настроек: при миграции на другую ОС переводятся службы и пакетная установка, а данные и контракты приложений сохраняются.

AgentBot — Telegram-клиент API OpenCode 2 с владельцем по Telegram ID и приватным SQLite-состоянием. Поддерживает HTTP и фиксированную команду транспорта; внутренняя интеграция и CTF-harness не входят в HomeLab. Проверены сквозной Telegram-диалог, остановка и восстановление после разрыва связи и перезапуска бота.
