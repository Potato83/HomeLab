# Закрытый CTF-Harness

Личный harness для агента, решающего CTF-задачи, хранится в отдельном закрытом репозитории. Этот проект содержит только описание интеграции.

Для установки требуется доступ к закрытому репозиторию. Клонируйте `git@github.com:<OWNER>/CTF-harness.git` и следуйте его README. Для скачивания и обновления можно использовать отдельный read-only deploy key.

Harness, инструментарий, конфигурация среды, задания и результаты в HomeLab не входят. Секреты не коммитятся даже в закрытый репозиторий.
