# Alpine

Текущий способ эксплуатации — OpenRC и Podman. Шаблоны служб ботов лежат в `apps/bots/*/deploy/`. Root-owned мониторинг хоста — в `apps/bots/serverbot/deploy/host/`.

При установке задайте локальные адреса и пути вне Git, проверьте права пользователей, health checks и обратимость обновления. Шаблоны не запускаются автоматически.

При миграции добавляйте настройки другой ОС и отдельный план переноса; не переносите секреты через Git.

Rest-server: `rest-server.compose.yml` фиксирует образ и ограничения, `rest-server.openrc` запускает существующий контейнер через Podman без API-демона. Перед созданием контейнера задайте свой VPN-адрес и UID/GID пользователя restic (в примере 1004). `/srv/restic` принадлежит этому пользователю; `.htpasswd` — root:restic с правами 0640. Аутентификация, private-repos и append-only включены. После установки службы проверьте HTTP 401 без авторизации и добавьте rest-server в runlevel default.
