# Alpine

Текущий способ эксплуатации — OpenRC и Podman. Шаблоны служб ботов лежат в `apps/bots/*/deploy/`. Root-owned мониторинг хоста — в `apps/bots/serverbot/deploy/host/`.

При установке задайте локальные адреса и пути вне Git, проверьте права пользователей, health checks и обратимость обновления. Шаблоны не запускаются автоматически.

При миграции добавляйте настройки другой ОС и отдельный план переноса; не переносите секреты через Git.
