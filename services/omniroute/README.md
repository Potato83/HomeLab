# OmniRoute

LLM gateway на Alpine: Podman запускает закреплённый OCI-образ, nginx ограничивает доступ к API и панели. OpenCode использует совместимый с OpenAI API.

`compose.yaml` — справочный контейнерный манифест; текущий сервер управляет контейнером через OpenRC. Не считать этот файл автоматической установкой сервера. `.env.example` содержит названия секретов без значений. Данные провайдеров и OAuth хранятся только на сервере.

Сначала создайте отдельные секреты, настройте закрытый сетевой доступ и требование API-ключа, затем выполните личную авторизацию провайдера. Проверяйте ответы API и запрет административных маршрутов для обычных клиентов.

В репозитории намеренно нет рабочих адресов, ключей, cookie и персональных bootstrap-скриптов.
